Install the Firefox extension

Try the Defeating Manipulation pattern highlighter in Firefox. It marks matching phrases on webpages and shows a short explanation when you hover over a highlight.

  1. Download the project ZIP and extract it.
  2. In Firefox, open about:debugging#/runtime/this-firefox.
  3. Click Load Temporary Add-on….
  4. In the extracted folder, select extension/manifest.json.
  5. Open a webpage and click the new toolbar icon to turn highlighting on or off.

This is a temporary developer installation, not yet a signed Firefox Add-ons release. Firefox removes temporary add-ons when it closes; repeat the last installation steps after restarting Firefox.
