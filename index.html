A shared knowledge base of language patterns.

Defeating Manipulation is a public, collaborative collection of recognised patterns in language and media. It is designed as a resource that AI tools can use to identify and explain matching patterns in online articles.

What this project does

The repository defines techniques, describes their observable features and records examples and references. AI analysis tools can compare article text against these definitions and show readers where patterns occur. The software identifies textual matches; readers decide what significance to give them.
